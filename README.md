# Fleet Management Dashboard

This is a fleet management dashboard built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Dashboard with sidebar, header, and footer
- Overview page with charts
- Vehicles page with a list of all vehicles
- Vehicle detail pages with real-time data gauges
- Settings page for user profile configuration

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
